# Укртелеком · інтернет по Україні

Партнерська сторінка для заявок на підключення інтернету Укртелекому. Frontend — чисті HTML, CSS і JavaScript; Node.js використовується для локального запуску, Netlify Functions — для Telegram-заявок у production.

## Локальний запуск

Потрібен Node.js 20 або новіший. Додайте `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID` у локальний `.env`, потім:

```powershell
npm start
```

Сторінка відкриється на `http://localhost:3000`. Не відкривайте її через Five Server: той не обслуговує `/api/lead`.

## Netlify

У репозиторії вже є `netlify.toml`, build script і Function для форми.

- Build command: `npm run build`
- Publish directory: `dist`
- Functions directory: `netlify/functions`

У Netlify відкрийте **Site configuration → Environment variables** і додайте `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID` як секретні змінні для production. Не комітьте токен і не додавайте його до frontend-файлів. Після цього запустіть deploy; форма надсилає заявки через `/api/lead`.

Для локальної перевірки Netlify Function можна встановити Netlify CLI та запустити `netlify dev`; CLI має читати секрети з локального `.env`. Звичайний `npm start` використовує Node endpoint у `server.js`.

## Telegram

Function перевіряє тип запиту, український формат номера та обмежує довжину полів. У повідомленні передаються тип звернення, ім’я, телефон, населений пункт, адреса, тариф і коментар. Bot token залишається тільки на сервері.

Якщо токен колись потрапив у публічний репозиторій, чат або лог, відкличте його через BotFather та оновіть локальний `.env` і змінну в Netlify.

## Області та населені пункти

Локальний довідник `settlements-data.js` містить до 20 поселень для кожної доступної області. Донецька, Луганська, Запорізька, Херсонська області, АР Крим і Севастополь навмисно відсутні у довіднику та відхиляються серверною перевіркою. Дані сформовані з GeoNames; за потреби оновлення використовуйте `scripts/generate-settlements.mjs` з файлами `UA.txt` та `admin1CodesASCII.txt` з GeoNames dump.

## Перед запуском

- Перевірте актуальність тарифів у масиві `tariffs` в `app.js`.
- Перевірте номери підключень `099 746 00 43` (08:30–18:30) і допомоги `044 440 0000` (цілодобово) перед публікацією.
- Підключіть власний домен у Netlify та лише після цього задайте canonical URL, sitemap і соціальне зображення з фактичною адресою сайту.
- Переконайтеся, що партнерська угода дозволяє використання логотипа Укртелекому.
